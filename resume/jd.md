# Object Storage 서비스 개발

## 부서소개

저희 부서는 Cloud 서비스의 핵심인 Object Storage의 연구 및 개발을 수행하는 부서입니다. Object Storage와 관련된 기술을 내재화하고 확산하여 고객에게 Cloud 서비스 형태로 제공하는 것을 목표로 합니다.

저희 부서의 신규 입사자는 입사 후 onboarding을 위한 트레이닝 기간을 거친 뒤 실제 개발에 참여하게 되며, 일반적인 REST API 개발 경험을 가지신 분들도 짧은 시간 내에 적응하실 수 있습니다.

## 주요업무

자체 Object Storage 솔루션 확보를 위한 기술 조사, 설계, 개발을 진행합니다. 서비스 출시 이후에는 서스테이닝 개발과 배포, 운영을 수행합니다. 아래 업무 중 본인의 보유 역량 및 앞으로의 커리어를 고려하여 담당 역할을 부여할 예정이니 참고 부탁드립니다.

• Object Storage의 클라우드 서비스 제공을 위한 API, Batch등 BE 개발
• HDD기반/SSD기반/NVMe기반/Tape기반 다양한 Storage Engine 개발
• Application 레벨의 Traffic shaping, QoS, MSA 등 다양한 영역에서 스토리지의 기반 기술을 개발
• Global scale의 분산환경에서 동작하는 분산시스템을 개발, 튜닝, 운영, 모니터링, 문제 해결

• Back-end 개발 경력을 3년 이상 보유하신 분

• Java, C/C++, Golang 중 적어도 1개에 대한 이해와 경험이 중급 이상이신 분
• CS 학부 전공자 수준의 전공 지식을 가지신 분
