## 해당 직무에 지원한 동기와 입사 후 이루고 싶은 개인의 목표가 무엇인가요? * 최대 1,000자 이내로 작성해주세요

개발자로서 경력의 시작은 임베디드 리눅스의 어플리케이션 개발로 클라이언트 사이드의 개발이였습니다. 개발 업무를 진행하며 경력을 이어나갈수록 데이터 관리와 처리방식의 중요성을 실감하게 되었습니다. 이후 자연스럽게 데이터를 관리하는 백엔드 개발 분야에 관심을 두게 되어 현재는 클라우드 파일 서비스의 백엔드 개발자로서 경력을 이어가고 있습니다. 더불어 업무와 병행하며 개인적으로 대규모 분산 시스템상에서 데이터의 저장 기술에 대한 이해를 높이고자 Key/Value Storage, 소규모 Object Storage, Raft 알고리즘등 관련 내용에 대한 주제로 개인 프로젝트를 진행하여 경험을 쌓도록 노력하고 있습니다. 

이러한 관심사를 바탕으로 국내 대표 클라우드 서비스를 제공하는 귀사의 여러 서비스에 대한 채용공고를 보게 되었습니다. 여러 클라우드 서비스들중 특히 Object Storage는 대용량 데이터를 안정적으로 관리, 처리하는 핵심 인프라라고 생각하며 제 경험과 관심사가 직접적으로 연관이 있는 직무라 생각하여 직접적으로 Object Storage 서비스를 만들어 나가고자 지원하게 되었습니다.

입사 후에는 우선 Object Storage 서비스의 아키텍처와 운영 환경을 빠르게 습득하고, 서비스의 안정성과 성능 개선에 적극 기여하는 것을 목표로 삼겠습니다. 이후에는 현재 서비스의 기술적 문제점이나 부족한 부분을 있다면 면밀히 검토하여 해결을 위해 연구한 기술이나 개선 과정들을 여러 동료들과 공유함으로써 조직과 함께 성장하고자 합니다. 이 과정으로 통해 궁극적으로는 만약 어느누군가가 어떠한 Object Storage 서비스를 사용해야할지 고민한다면 결론적으로 NCP의 Object Storage 가 선택되도록 만드는데 핵심 역할을 수행하고자 합니다.

## 최근 관심있게 보고 있는 기술 또는 산업 트렌드를 간략히 소개해주세요. (기술 및 시장 트렌드에 대한 소개, 관심있게 본 까닭 등) * 최대 800자 이내로 작성해주세요

최근 기술적 트렌드를 이야기 할때는 AI 를 빼놓을수 없다고 생각합니다. 이에 대하여 현재 관심을 가지는 분야는 AI 가 발전함에 따라 필요한 데이터 혹은 새로 생성되는 데이터의 처리 및 관리 방법 입니다.  대규모 AI 모델은 방대한 데이터를 기반으로 학습하고 처리하기 때문에 단순히 AI 모델의 성능뿐만 아니라 데이터를 어떻게 효율적으로 저장하거나 처리할 수 있는지가 또다른 핵심 경쟁력으로 알고 있습니다.
특히, 최근 AI 를 활용한 서비스가 확산될수록 저장 공간의 효율성, 대규모 트래픽 처리 성능, 대규모 데이터 처리 방법과 같은 기술적 내용들이 더욱 중요해지고 있다고 생각합니다. 이러한 문제들을 해결하기 위해 대규모 비정형 데이터를 관리를 위한 분산 object storage를 활용과 I/O 병목을 최소화하기 위한 데이터 로컬리티 최적화 방법 혹은 분산 캐싱 패턴 적용, 그리고 대규모 데이터의 관리 비용을 최소화 하기 위한 스토리지 계층화등 AI 가 발전함에 따라 데이터 관리 전략 및 인프라 전반에서 분산 스토리지, object storage, 벡터 DB, 실시간 데이터 처리와 같은 기술들이 빠르게 발전하고 있는것으로 알고있습니다
현재 혹은 미래의 AI 시대의 핵심 경쟁력은 결국 데이터를 어떻게 다루느냐에 달려 있다고 생각하며. 이러한 변화 속에서 Object Storage 가 이러한 AI 시대의 핵심 인프라중 하나라고 생각하고 있습니다. 또한 AI의 발전은 지속될 것이라고 생각하며, 이를 뒷받침할 수 있는 대규모 데이터 처리 및 관리 기술을 지속적으로 확인해 나가고자 합니다.

## 협업시 동료와 의견차이나 갈등이 있을 때, 해결한 경험이 있으면 말씀해 주세요. * 최대 2,000자 이내로 작성해주세요

저의 향후 성장 목표는 고성능, 확장성 그리고 안정성을 두루 갖춘 백엔드 시스템 설계, 개발 및 운영이 가능한 전문가로 자리매김하는 것입니다. 이러한 목표를 달성하기 위해선 수많은 사용자들이 사용하는 클라우드 서비스와 같은 대규모 시스템의 기술적 깊이와 전체를 바라보는 시야가 필수적이라고 생각합니다. 특히, Object Storage와 같은 대용량 데이터를 처리하는 핵심 인프라 분야에서 깊은 이해와 실무 경험을 쌓아, 고가용성과 성능 최적화를 동시에 추구하는 개발자로 성장하고자 합니다.

둘째, 아무리 뛰어난 기술이라도 사용자 경험이 미흡하면 선택받지 못한다고 생각합니다. 따라서 기술적 향상에만 중점을 두지 않고 사용자 경험 또한 향상시키기 위하여 사용자 니즈를 생각한 API 설계, 성능 모니터링, 반복적인 개선 과정을 통해 서비스의 질적 향상을 시키고자 합니다. 또한  이 과정에서 동료와 성취를 공유하며 일의 즐거움을 찾고자 합니다.
